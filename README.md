# Around the U.S.

## ¿De qué se trata?

Este proyecto es una galería de fotos de distintos lugares. Puedes ver las imágenes en una cuadrícula y si le das clic se abre una venta para editar tu perfil. Está hecho para verse bien tanto en compu como en tablet y celular.

### Qué hace

- Muestra las fotos en una galería
- Al hacer clic se abre una ventana para editar tu perfil
- El modal se puede cerrar con el botón, dando clic afuera.
- Se adapta a cualquier tamaño de pantalla

## Cómo lo hice

- HTML para la estructura
- CSS con metodología BEM para tener los estilos organizados
- JavaScript para que funcione el modal
- Flexbox y Grid para que se vea bien en cualquier pantalla
- Usé Git y GitHub con ramas para ir guardando mi progreso
